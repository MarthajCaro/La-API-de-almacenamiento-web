# 💰 Control de Gastos Personales

Una aplicación web interactiva diseñada para gestionar y visualizar gastos diarios y mensuales. Permite a los usuarios registrar sus finanzas de manera rápida, categorizarlas y mantener un historial persistente en el navegador.

## 🚀 Deploy

https://marthajcaro.github.io/La-API-de-almacenamiento-web/

## 🛠️ Tecnologías utilizadas

- **HTML5:** Estructura semántica de la aplicación.
- **CSS3:** Diseño responsivo (Mobile First), uso de Flexbox y CSS Grid para la maquetación.
- **JavaScript (Vanilla):** Manipulación del DOM, lógica de filtrado por fechas y persistencia de datos.

## ✨ Características principales

- **Persistencia de datos:** Uso de `localStorage` para que los gastos no se pierdan al recargar la página.
- **Cálculos automáticos:** Filtrado dinámico utilizando métodos de arreglos (`filter`, `reduce`) para mostrar el total gastado en el día actual y en el mes.
- **Desglose por categorías:** Agrupación inteligente de gastos (Comida, Transporte, Servicios, etc.) iterando sobre objetos dinámicos.
- **Diseño Responsivo:** Interfaz adaptable a dispositivos móviles y de escritorio.
